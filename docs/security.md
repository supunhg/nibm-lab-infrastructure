# Security findings & status — dell-node01

Audit date 2026-10-31. Status: FIXED / OPEN / ACCEPTED.

| # | Severity | Finding | Status | Fix |
|---|---|---|---|---|
| 1 | Critical | Qdrant had no authentication; anyone on LAN/ZeroTier could read or delete all collections (REST 6333, gRPC 6334). | FIXED | Master API key + JWT RBAC. `qdrant.lab` dashboard behind Authentik forward-auth (approved users only); `qdrant-api.lab` validates key / per-user JWT. Direct ports firewalled to ZeroTier + admin workstation. |
| 2 | Critical | No host firewall; every service port (incl. Portainer = root via Docker socket, ESXi relay, NAS relay) open to the whole LAN. | FIXED | `/etc/iptables/rules.v4`: LAN may reach only 22, 9993/udp, 80, 443, 53, 853, 25565, 2222. Docker-published ports filtered in `DOCKER-USER` by original dst port. ZeroTier, Docker bridges and 192.168.1.50 trusted. |
| 3 | High | `rules.v4` was a snapshot of Docker's runtime chains (stale container IPs restored every boot). | FIXED | Rewritten with host rules only; Docker manages its own chains. Never run `netfilter-persistent save` while Docker runs. |
| 4 | High | SSH: password auth, root login, X11 forwarding; no brute-force protection; a second key (Antigravity/id_ed25519) authorized. | FIXED | `sshd_config.d/00-hardening.conf` (keys only, `AllowUsers admin`), fail2ban `sshd` jail, extra key removed (backup `~/.ssh/authorized_keys.bak-*`). |
| 5 | High | No backups. | FIXED | Nightly encrypted restic → Synology, 7d/4w/6m retention, weekly integrity check, Kuma push monitor + ntfy on failure. Restore tested. |
| 6 | High | Vaultwarden open signups; `DOMAIN` was http (web vault crypto needs HTTPS). | FIXED | `SIGNUPS_ALLOWED=false`, `DOMAIN=https://vault.lab`. |
| 7 | Medium | Secrets in plaintext in `docker-compose.yml` (world-readable). | FIXED | Moved to `/opt/homelab/.env` (600). Old DB passwords kept (baked into data). |
| 8 | Medium | 15 images on `:latest`. | FIXED | All pinned (tags or digests); Diun reports new tags to ntfy. |
| 9 | Medium | NAS CIFS mount failed at boot (network race) — Jellyfin had no media for 2 weeks unnoticed. | FIXED | `x-systemd.automount` + `rslave` bind propagation. |
| 10 | Medium | MeshCentral trusted a stale proxy IP; weak static session key. | FIXED | NPM pinned to 172.18.0.10, `trustedProxy` updated, session key rotated. |
| 11 | Medium | Unbounded Docker logs. | FIXED | `daemon.json`: `local` driver, 10 MB × 3. |
| 12 | Low | `fileserver.service` (python http.server :8081) serves `/opt/homelab/downloads` without auth. | ACCEPTED | Now reachable only from ZeroTier/admin. Contents are PDFs + Minecraft mods. Disable with `sudo systemctl disable --now fileserver` when no longer needed. |
| 13 | Medium | NPM-managed hosts (numbered confs) serve plain HTTP on :80 without redirect; admin UIs (portainer/proxy/dns.lab) reachable by anyone resolving `*.lab`. | FIXED | 2026-11-01: all 24 hosts generated by `gen-npm.sh` (HTTPS redirect, HSTS, nosniff); admin consoles behind Authentik (homelab-admins); NPM UI host records disabled. |
| 22 | High | App accounts (forum, Forgejo) were unrelated to lab identities: anyone could register any name; leavers kept access. | FIXED | Student usernames = index numbers (`co…-NNN`, enforced at registration). forum.lab members-only; forum `/register` and Forgejo `/user/sign_up` require lab login and identical username/email (`identity-guard.lua`). `lab-account-sync` (2 min) confirms matching accounts and suspends Forgejo login for disabled lab accounts. Verified by `scripts/test-identity-binding.sh`. |
| 14 | Low | Existing DB passwords (n8n, Flarum) were exposed in plaintext compose history. | OPEN | Rotate with `ALTER USER` + `.env` update when convenient. |
| 15 | Info | `id_ed25519` and `claude_ubuntu_server` private keys on the admin desktop are not passphrase-protected; any local agent with file access can use them. | ACCEPTED | "SSH only via Claude" is policy, not technically enforceable on a shared desktop. |
| 16 | Critical | Speedtest Tracker still had the factory admin `admin@example.com` / `password` — anyone on campus could log into its admin panel. | FIXED | 2026-11-01: random password (`SPEEDTEST_ADMIN_PASSWORD` in `.env`), email changed to the admin's. |
| 17 | High | Every `qdrant-users` member received the Qdrant **master key** via the dashboard proxy (could delete all collections). | FIXED | Per-login JWT minted by Authentik (`homelab-qdrant-jwt`), tiers: readers (r), per-collection grants (`qdrant_collections`), managers/admins (m). Verified by `scripts/test-qdrant-tiers.sh`. Copied keys stay valid until expiry (default 7 days); master-key rotation revokes all. |
| 18 | High | Registration accepted duplicate emails/usernames — enables account takeover in apps that link by email. | FIXED | Expression policy `homelab-unique-username-email` on the enrollment prompt. |
| 19 | Medium | No admin account separation: daily admin work used the bootstrap `akadmin`. | FIXED | Personal admin `supun` (superuser), `akadmin` kept as break-glass (email moved to akadmin@nibm.lab). Set up via one-time recovery link. Recommend TOTP on `supun`. |
| 20 | Low | Vaultwarden runs `DISABLE_ADMIN_TOKEN=true`; `/admin` protection relies on the Authentik gate at vault.lab. Direct port 8088 bypasses it. | ACCEPTED | 8088 is reachable only from ZeroTier + the admin PC (firewall). Keep ZeroTier membership to trusted admins. |
| 21 | Medium | Certificate is a self-signed `*.lab` wildcard; `.lab` is a public TLD so browsers never fully trust it, and server-to-server OIDC (SSO) cannot verify it. | OPEN — awaiting approval | `scripts/pki-issue.sh` ready: name-constrained internal root CA (only `.lab` + campus IPs) + per-host SAN certificate, auto-renewal timer, trust bundle for containers. Blocked pending owner approval of certificate changes. |
